
# Super Mario Clone

这是一个使用 Python 和 Pygame 库开发的简单马里奥克隆游戏。

## 游戏功能

*   **玩家控制**：使用键盘方向键左右移动，空格键跳跃。
*   **平台跳跃**：包含地面和悬浮平台。
*   **敌人**：简单的巡逻敌人。
    *   碰到敌人侧面或底部会死亡（游戏结束）。
    *   跳到敌人头顶可以消灭敌人。
*   **胜利条件**：到达金色方块处即可获胜。

## 安装与运行

1.  确保已安装 Python 3。
2.  安装 Pygame 库：
    ```bash
    pip install pygame
    ```
3.  运行游戏：
    ```bash
    python mario.py
    ```

## 操作说明

*   **左箭头 (←)**：向左移动
*   **右箭头 (→)**：向右移动
*   **空格键 (Space)**：跳跃

## 游戏规则

*   躲避或消灭棕色方块敌人。
*   利用绿色平台向上跳跃。
*   触碰金色方块获得胜利。
